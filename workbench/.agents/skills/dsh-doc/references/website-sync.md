# Documentation website scope

The standalone upstream VitePress site, page allowlist, and projector are not included in this Weave Workbench workspace. The former `website/docs.ts`, `website/.vitepress/config.ts`, and `scripts/project-doc-site.ts` paths identify historical implementation files; they are not current editing or execution targets.

Canonical repository Markdown and sibling bilingual files remain the maintained content. Follow [the documentation standard](../../../../docs/AGENTS.md) and [pairing contract](../../../../docs/i18n/README.md). Product setup and deployment belong to the repository root [README](../../../../../README.md).

Do not recreate a standalone publishing workflow while repairing documentation references. Website publication requires an explicit product decision and its own implementation and validation.
