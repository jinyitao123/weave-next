# Agent Note：成员执行配置发布

Status: implemented

[English](2026-09-06-member-execution-publication.md) | 中文

## 问题

只保存成员的引擎选择，会让已发布工作流继续使用不同的冻结配置。

## 决策

Weave 在同一事务中更新成员版本并发布受影响的工作流。草稿冲突或候选验证失败会回滚整次修改。已有任务保留原配置。CLI 原生模型名称保存在冻结成员记录中，无须平台服务绑定。

## 考虑过的替代方案

**先保存再发布。** 发布失败会让下次任务使用的配置与页面不同。

## 影响

浏览器在切换引擎时清空模型选择。节点默认值描述配置，执行回执确定报告的模型。公共尝试历史不代表模型正文或最终交付。浏览器和 Host 回归验证模型清空、凭据排除与冲突处理，数据库验证发布及回滚。
