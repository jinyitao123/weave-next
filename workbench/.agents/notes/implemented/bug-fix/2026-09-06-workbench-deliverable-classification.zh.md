# Agent Note: Workbench 交付物分类

Status: implemented

[English](2026-09-06-workbench-deliverable-classification.md) | 中文

## Problem

Weave 更正成员中间文件的分类后，WorkTask 缓存仍可能保留最终标签，因为文件数量没有变化。这会把未完成的团队工作呈现为可用的最终交付。

## Decision

Host 将已发布工作流中非交付节点的文件视为阶段产物。精确运行的活动引用可以直接把缓存文件改判为阶段产物，无需重新获取正文。文件内容与身份保持完整。交付节点仍保留最终文件与结论分类。

## Alternatives considered

**仅在文件数量变化时刷新。** 分类可以独立于数量发生变化，因此会留下错误标签。

**每次轮询重新获取全部文件。** 活动响应已经提供权威的阶段分类，重复读取大量正文不会增加证据。

## Consequences

当前视图遵循 Weave 的分类，保留的历史快照不变。缺少活动引用不会删除已知文件，也不会虚构最终交付。回归记录一个最终文件，应用文件数量相同的活动观测，并验证阶段标签及未变的正文。
