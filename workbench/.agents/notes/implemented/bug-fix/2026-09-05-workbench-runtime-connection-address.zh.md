# Agent Note: Workbench 运行节点连接地址

Status: implemented

[English](2026-09-05-workbench-runtime-connection-address.md) | 中文

## 问题

Workbench 在创建节点后只返回一次性运行令牌，页面展示的连接命令仍含服务地址占位符。用户必须自行寻找并替换地址，尽管 Host 已经知道 Weave API 端点和本机网络接口。

## 决策

Workbench Host 现在会在启动时解析一个具体的运行节点服务 URL。显式 `WEAVE_RUNTIME_SERVER_URL` 优先，表示部署的公网或其他可路由 URL。未设置时，已经可路由的 `WEAVE_API_URL` 保持不变。回环、通配以及仅容器可见的单标签主机名会回退到优先外部 IPv4 接口，优先选择 RFC 1918 地址，并保留 API 协议、路径和端口。基准测试地址与链路本地地址不会进入回退选择。

运行节点创建响应会把该服务 URL 与一次性令牌一起返回。浏览器校验两个值，完成 shell 引用，展示不含占位符的完整命令，并提供直接复制连接命令的操作。一次性展示期间仍保留原始令牌，供需要单独令牌的安装流程使用。

容器部署会把 `WEAVE_RUNTIME_SERVER_URL` 传入 Workbench，因为仅容器可见的 `WEAVE_API_URL` 无法说明其他机器可达的地址。裸机安装可留空并使用内网发现。

## 验证

Host 聚焦测试覆盖已配置公网 URL、可路由 API URL、回环及容器主机内网回退，以及创建响应合同。浏览器聚焦测试覆盖完整命令展示与剪贴板内容。

## 考虑过的替代方案

**让浏览器用户填写 Weave 地址。** 未采用，因为服务路由属于部署信息，Workbench 可以直接提供完整命令。

**通过外部服务发现公网 IP。** 未采用，因为出口地址不能证明入站可达性、端口转发、TLS 或正确的公网主机名。

## 影响

新运行节点会获得可以直接执行的命令。公网部署只需在部署层配置一次可路由 URL；本地裸机安装会自动使用优先内网地址。如果主机既没有配置可路由 URL，也没有可用的外部 IPv4 接口，解析器会保留原 API URL，使同机连接仍然可用。
