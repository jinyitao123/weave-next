# Python SDK availability

English | [中文](python-sdk.zh.md)

The standalone Python SDK and its bundled runtime are not included in this Weave Workbench workspace. This page provides no SDK installation or standalone profile instructions. Use the repository root [English setup guide](../../../../README.md) or [Chinese setup guide](../../../../README.zh-CN.md) for the supported product.

The retained JSON-RPC [protocol](../../../packages/sdk/protocol/README.md) and [server](../../../packages/sdk/server/README.md) are runtime infrastructure, not a separately supported SDK distribution.
