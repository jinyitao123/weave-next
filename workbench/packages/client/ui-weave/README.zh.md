# `@deepseek-ai/dsh-client-ui-weave`

[English](README.md) | 中文

## 概述

Workbench 在挂载业务页面前先确认账号。未登录时提供账号、密码和可选工作区；侧栏可查看当前用户并退出。密码在提交后立即清空，不写入浏览器存储，认证凭据由 Host 在 HttpOnly Cookie 后保管。登录和退出成功后重新加载工作台，登录失效时立即隐藏旧视图并丢弃迟到的业务响应；聚焦页面、定时检查及支持的浏览器标签页通知会继续核对账号变化。

`dsh-client-ui-weave` 把持久化的 Weave MCP 调用结果转成可见的工作任务，并把运行节点管理放进同一个 Workbench 界面。用户无需阅读内部编号或工具术语，就能跟踪已选团队、进度、成员活动、运行位置、人工决策和严格归属当前运行的交付物。

账号角色决定 Host 管理入口是否可见。普通成员无需选择目录即可新建个人任务，侧栏显示个人任务列表，并可归档自己的任务；管理员保留共享项目与 Host 设置入口。个人新建不发送路径或工作区覆盖值，合并未完成的重复点击，身份失效后丢弃旧创建结果的导航；实际授权和目录归属仍由 Host 决定。

## 使用此包

在 `ui-chat` 和 `ui-tool` 之后挂载本包。设置页负责运行节点管理。会话标题旁的任务入口默认在对话旁打开现有工作现场，全幅查看需要用户主动选择。现场的团队和成员阅读共用固定的“总览”“进展”和“成果”页签。各视图分别保留主滚动位置，也覆盖从对话回执发起的导航。执行中优先展示恢复、纠偏和成员。失败任务默认打开进展，在现场和主对话的紧凑回执中说明失败阶段，并可展开原始原因。首次打开已完成且有最终交付的任务时默认选择总览；缺少最终交付时选择成果。已停止任务在有保留成果时选择总览。阅读期间任务完成会保留当前页签。已派发任务缺少团队名称时，不再显示正在匹配团队。页签选择和最多三名关注成员属于浏览器阅读偏好。成员执行记录展示实际运行位置、阶段、可读输入、工具活动及可直接展开的已有产物。“提出调整”在原输入框插入可读引用，保留已有草稿且不自动发送。引用携带确切的运行、成员、阶段和产物身份，供后续讨论使用；它不建立独立成员对话或独立暂停。

成员优先使用已记录的可读名称。空名称、UUID 以及与内部成员标识相同的名称显示为“团队负责人”或“成员 N”；重复的展示名称追加名册位置序号。工作现场、关注列表、恢复责任人、纠偏对象和调整引用共用这些名称。原始标识保持不变，并保留在折叠的运行识别信息中。序号只表示名册位置，不代表新建或持久化的身份。

现场内容列最大为 880px，长正文保留 72ch 阅读宽度。布局按现场容器自身宽度调整，也覆盖大屏中的窄分栏。成员行将首字头像、身份、状态和进入箭头对齐到固定列，职责保持一行次要文字，完整职责留在成员记录中。单个执行阶段不再套额外外框，元信息与下载操作在视觉上弱于公开正文和成果标题。

总览按已记录的文件格式列出最多三项最终输出，交付结论、网页、图纸、表格和文档排在辅助代码及日志之前，同时提供团队成员、任务要求和去重后的输入路径引用。输入引用不表示成员已阅读该来源。总览的成员入口回到成员列表起点，普通页签切换仍保留阅读位置。全部输出包含阶段文件，在有五项及以上输出时支持按文件名查找。精确成果链接会清除冲突的搜索并展开目标文件。已处理的调整记录默认折叠，进行中的调整和失败继续保留原有进展操作。

主对话通过 `conversation.input.dock` 保留一张紧凑任务回执。Workbench 将它放在固定输入框上方的正常文档流中，随对话滚动，不覆盖之前的消息。它仅展示当前状态、可用操作、最终成果直达入口和阶段产物数量。完整成员记录、成果预览与操作历史留在工作现场。顶部使用线框工作现场图标及小型状态角标；悬停和键盘聚焦时显示现场名称、当前状态与进度。人审答复和纠偏范围由用户主动展开；重试、停止和纠偏确认仍可在主对话完成。已处理操作在现场保留真实的接收或拒绝回执，接收请求不表示执行完成。历史提交内容明确标注为“此前提交的回答”。人审表单沿用 Weave `resume_schema` 声明的字段名和类型；复杂结构引导回到讨论，不擅自构造自由文本答复字段。普通提问不会自动提交纠偏。

选择团队会请求查看方案，不构成派发授权。尚未产生运行时，紧凑回执和工作现场仍显示创建状态，包括提交中、构建中、已就绪、失败和结果未知。Host 根据已记录的构建标识调用现有构建进度路由，现场只展示实际返回的步骤与尝试次数。传输错误保留结果尚未确认的创建记录，不回退为匹配团队。结构化提问和计划审阅在对话中保留方案内容与用户答复；本包不引入带版本的授权存储或执行权限检查。

等待任务区分定时暂停、团队阶段、人审答复、纠偏确认和执行环境中断。当 Weave 明确当前中断阶段尚在等待原执行停止确认时，主对话、工作现场和成员记录指出对应阶段，并说明先恢复运行节点连接。仅在 Weave 返回该阶段可重试后提供入口，不将确认尚未到达说成永久无法恢复。重试必须对应当前可恢复的确切等待，运行中、停止中和终态不会露出旧失败的重试入口。只有已确认取消才显示“已停止”；仅在 Weave 根据对应取消状态迁移返回 `stop_unconfirmed` 时，显示停止状态未能确认。运行完成却缺少 `artifact_kind=final` 最终产物时，页面明确保留交付缺口，并提供核对已有工作的入口。最终文件和无文件名的最终结论表示有可打开的输出，均不能证明交付已通过核验。

工作现场和主对话回执分别展示执行状态、交付核验（`pending`、`passed`、`failed` 或 `unknown`）和用户评价。现场可查看各项已记录检查的状态与原因。缺少核验记录时保持未知，正文中的 PASS 等文字不能作为核验结论。只有执行完成、具备最终输出且交付版本可用时才能评价。没有版本的历史成果仍可阅读，评价按钮停用并说明原因。每次评价请求携带点击时页面所展示的版本。同一版本重新核验时，Host 刷新保留用户评价；新版本会清除评价。浏览器仅展示属于当前所示版本的评价。

核验详情提供重新核验入口，只对已保存成果执行已登记的检查，不重跑成员。请求捕获页面所示的交付版本和要求摘要，缺少任一项时按钮停用并说明原因。收到请求确认后，页面继续展示原核验结论，等待 Host 发布已保存的报告；冲突原因保持可见。重新核验无法补足尚未支持的检查。

成员公开更新依据实际运行节点能力展示。新近观测到执行中时，每个任务区域只在主要任务状态处轻微闪动，成员状态点和团队候选卡保持静止。主对话和工作现场指出正在执行的成员，对应阶段运行时最新公开记录短暂高亮，不生成占位文字流。停止确认等待、过期观测、停止中和终态保持静止，并尊重减少动态效果偏好。支持的新版本 Codex 节点可在执行中发布公开文字和工具事件，其他或旧节点在阶段完成后更新。公开记录与最终成果分开，不包含私有推理。长记录先显示原文片段，并提供明确的展开入口。用户向上阅读历史时，新记录不会抢占滚动位置；即使没有未读内容，也可主动回到最新记录。截断状态明确可见。返回成员或页签时保留成员选择及最多 100 个阅读位置，包括跟看、未读及记录展开状态。列表前部记录被移除时，仍保留的记录通过记录身份和视口偏移维持历史阅读位置；已被服务端移除的记录无法恢复。

项目成果链接回到原对话并展开确切保留产物。侧栏项目动态只读取工作区明确关联会话的当前持久化任务，同一运行按最新观测去重，排除归档和未关联会话，并明确说明缺失记录。任务和成果入口返回原工作对话；取得最终产物不等于质量已验收。

设置页提供成员执行配置。切换引擎会清空原模型名称和备用模型。工作流发布成功后，所选运行节点和有限重试策略应用于后续任务。节点详情区分配置服务地址、节点默认模型和执行回执报告的模型。公开尝试记录描述实际执行历史，不代表模型正文或最终交付。

<a id="understand-the-implementation"></a>
## 理解实现

浏览器复用工具视图、会话标题、详情、输入框附属区、设置和工作区项目动态插槽。Host 负责持久化 `workTask` 投影、后台轮询，以及鉴权后的任务操作与正文路由。浏览器消费 Host 推导的 `displayState`，统一任务状态文案。浏览器展示和阅读偏好不形成另一套执行状态。项目导航等待目标会话视图实际就位后再打开现场，避免会话切换时的布局清理关闭刚请求的现场。

运行节点创建后，浏览器校验 Host 返回的服务地址与一次性令牌，展示经过 shell 引用处理的完整连接命令，并可直接复制该命令，不再要求用户替换服务地址占位符。

产物正文首次展开后渲染，收起和切换页签时保持挂载。SVG 缩放和表格位置保留在该文件视图中，换为其他文件时重置预览。已知人审结论格式优先展示决定和批注，原始 JSON 可进一步展开。Markdown 使用共享渲染器；SVG 通过鉴权正文路由以图片展示，并带沙箱 CSP；HTML 使用受严格 CSP 约束的静态沙箱文档。CSV 与 TSV 表格最多预览 200 行、40 列；SVG 图片提供明确缩放控件。预览受限时使用真实完整正文下载入口。完整下载经 `/api/weave.deliverable` 转发到 Weave 现有 `/v1/deliverables/:id/content`，即使投影预览被截断仍可读取后端保留的完整正文。Host 校验会话、运行和产物的关联，不向浏览器暴露业务密钥，也不从生成文字中猜测本地路径或应用访问地址。

<a id="model-experience"></a>
## 模型体验

无独立模型调用，因为浏览器包通过现有对话提交用户明确选择的引用和讨论内容。

#### KV Cache 影响

投影刷新不增加模型上下文；用户明确提交的内容会扩展现有对话，并正常影响其上下文和缓存。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- **每个 Session 只展示一个任务**——当前投影跟踪 Session 中最近一次 Weave 派发；多派发任务分组仍暂缓。
- **运行进程仍由所在机器控制**——运行节点中心管理注册与调度事实，不会声称可以从浏览器启停本地 Codex、Claude Code、OpenCode 或内置执行进程。
- **紧凑 JSON 是输入合同**——非数组结果，或缺少稳定 ID 与名称的团队条目，会进入格式异常状态。
- **交付物是远端不可变文件**——Workbench 可以预览和下载已记录正文，但不会把它物化到当前工作区。
