# Weave Workbench 运行底座

[English](README.md) | 中文

本目录包含 Weave Workbench 使用的 TypeScript 运行底座和浏览器界面，只随仓库根目录的完整产品构建与发布，没有独立安装、发布或支持入口。

在仓库根目录运行受支持的检查：

```sh
make workbench-install
make workbench-check
```

产品安装、部署、贡献和支持说明统一放在根目录的[英文 README](../README.md) 与[中文 README](../README.zh-CN.md)。原 MIT 许可证及第三方声明继续保留在本目录。
