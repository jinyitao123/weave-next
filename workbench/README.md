# Weave Workbench runtime

English | [中文](README.zh.md)

This directory contains the TypeScript runtime and browser interface used by Weave Workbench. It is built and released only as part of the repository root product. It has no independent installation, release, or support channel.

Run its supported checks from the repository root:

```sh
make workbench-install
make workbench-check
```

Product setup, deployment, contribution, and support instructions live in the root [English README](../README.md) and [Chinese README](../README.zh-CN.md). The original MIT license and third-party notices remain in this directory.
