# 受限选择决策接口

> 状态：2026-10-02 提出，待仓库负责人评审。它替换此前为单一演示写入的 `/v1/game-decisions`。

## 目的

服务端调用方把一份冻结的输入交给一个已发布的团队工作流，要求它从调用方给出的选项中**恰好选一个**，并读回选择、运行证据和各模型节点的过程记录。Weave 只负责与领域无关的不变量；调用方的领域词汇（字段、枚举、可见范围、提示语）作为数据登记在绑定合约里，不写进 Weave 代码。

## 不变量（Weave 负责）

| 不变量 | 实现 |
| --- | --- |
| 只能从冻结选项中选 | 读回时按合约的 `choice_pointer` 取出选择，核对它属于输入 `options_pointer` 处的选项 ID |
| 输入冻结、可复算 | 顶层键排序、嵌套值原样保留后计算 SHA-256；同一请求 ID 改输入或改通道即 409 |
| 同通道串行 | `(工作区, 服务密钥, lane)` 上的数据库咨询锁；未终止的前一个请求通过 `X-Decision-Active-Request-ID` 告知调用方 |
| 取消不可被迟到请求绕过 | 取消墓碑先于准入记录也能写入，之后同一请求永不准入 |
| 执行版本冻结 | 绑定指向一个已发布工作流版本；准入行同时冻结当时的合约 |
| 不扩大权限 | 工作流只能含 lead、worker、transform、condition、parallel、join 和唯一一个本地 deliver；所有成员必须是 Loom 模型成员、禁用全部工具，无记忆、技能、MCP、运行时或备用模型；worker 必须声明输出 schema |

`lane` 是调用方自定的不透明并发键（1–64 位字母、数字、`_`、`.`、`:`、`-`），Weave 不解释它的含义。

## 合约（调用方负责，登记为数据）

```json
PUT /v1/decision-bindings/{key_id}
{
  "team_id": "…", "workflow_id": "…", "workflow_version": 3,
  "contract": {
    "input_schema":  { "type": "object", "additionalProperties": false, "...": "…" },
    "output_schema": { "type": "object", "required": ["queue_id"], "...": "…" },
    "options_pointer": "/queues",
    "option_id_field": "queue_id",
    "choice_pointer":  "/queue_id",
    "instruction": "可选，≤4000 字节，附加在平台说明之后",
    "max_options": 10000
  }
}
```

- JSON Schema 不允许外部引用；绑定时编译失败即拒绝。
- 服务密钥必须只有 `decisions` 一个 scope。
- 可见范围之类的领域防护（例如“输入不得含其他参与者的私有数据”）由调用方在 `input_schema` 中用 `additionalProperties: false` 等声明，Weave 在准入时强制执行。

## 调用

| 接口 | 说明 |
| --- | --- |
| `POST /v1/decisions` | `{client_request_id(UUID), lane, input}`；返回 201 与 `X-Decision-ID`、`X-Decision-Input-Hash` |
| `GET /v1/decisions/{decision_id}` | 状态、`lane`、`run_id`、工作流版本、`trace.nodes[]`；成功时另含 `choice` 与交付节点成员身份（`agent_id`、`model`、`engine`、`decider_node_id`） |
| `POST /v1/decisions:cancel` | `{client_request_id, lane}`；写取消墓碑并请求终止运行 |

`trace.nodes[]` 按图顺序列出模型节点：`node_id`、`type`、`label`、`agent_id`、`agent_name`、`model`、`status`（pending / running / succeeded / failed / skipped / cancelled）、起止时间、耗时，以及成功节点的输出。它只投影本次运行已有的成员、活动事件和阶段交付物，不新增状态。

## 迁移

迁移 `0177_bounded_decisions.sql` 删除三张 `weave_game_decision_*` 表，新建 `weave_decision_*` 表，并把仅含 `game_decisions` scope 的密钥改为 `decisions`。原有运行、交付物和用量仍在运行台账中。旧绑定不做数据转换：唯一的既有调用方随本变更重新登记带合约的绑定。
