# Weave 架构文档

Weave 只为 Workbench 提供执行后端。业务操作在 Workbench，内嵌运行时页面只供维护者使用。独立 Codex/Claude 客户端、业务 CLI 和旧 Console 产品方案已删除，不再保留另一套产品路线。
