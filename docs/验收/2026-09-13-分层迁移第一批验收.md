# 分层迁移第一批验收

日期：2026-09-13。分支：`codex/layering-capability-runtime`。代码提交：`a6b0b89a`。

结论：已完成能力 API 的执行职责提取，以及能力定义、编译和执行语义迁入内核。工程检查与隔离 PostgreSQL 回归通过。真实 Workbench 浏览器验收受工具连接故障阻塞，不能据此宣称整体分层、多运行时团队或交付验收完成。

## 本批约束

用户明确本次迁移不承担旧数据及其他存量兼容。实现直接采用新契约，未增加旧数据读取、快照转换、旧 Host 适配、转发包或双轨执行。新系统的发布冻结、身份隔离、幂等、取消及恢复仍须成立。

继续保留 Loom 执行、外部智能体完整执行及 Loom 经外部智能体获取推理的产品方向。本批只提取现有能力执行入口，未修改团队运行时组合或推理来源的产品选择方式。

## 实际职责变化

| 对象 | 迁移后职责 | 本批边界 |
|---|---|---|
| `internal/kernel/capability` | 能力定义、冻结修订、schema 校验、计划编译、条件与并行、人工等待和恢复等执行语义 | 从 `base/capability` 整体迁入。该契约描述内核的能力语义且无基础层调用者，未为迁移拆出转发 DTO 包 |
| `internal/kernel/capabilityruntime` | 选择运行时，把步骤绑定到 Loom 或外部成员执行器 | 接收执行请求与记录接口，不导入 app/build，不持有产品数据库；不领取任务、不续租、不重派整项任务、不自行写调用终态 |
| `internal/app/capabilities` | 接入调用记录、领取循环、检查点和运行关联持久化 | 记录接口以工作空间、调用、任务、执行凭据、状态及租约校验写入；现有任务生命周期仍在本层，待下一批收敛 |
| `internal/app/api/capability_runtime.go` | 服务与内核依赖装配 | 已移出运行时选择、成员提示构建、运行关联 SQL 及领取循环；删除原选择/校验转发方法，调用方直接使用 Runner |

能力内核通过步骤接口使用执行器；运行时绑定通过记录接口保存观察。API 只负责把模型解析、运行时目录、远程执行器和现有持久化设施接起来。这里没有新建第三套队列或运行状态机。

## 发现的问题与修复

| 用户会遇到什么 | 证据与原因 | 处理与验证 |
|---|---|---|
| 执行失联后，同一项工作可能又被派发一次 | 原能力租约过期会直接回到队列；检查点无法证明最后一次外部操作是否发生 | 过期任务转为失败并记录 `capability_execution_lease_expired`，不自动重派。既有真实数据库测试曾明确要求“不重试”但未设置数据库时会跳过；本批实际运行并通过 |
| 已失效或已取消的执行仍可能续期，旧执行可能覆盖运行环境归属 | 续租原来只校验任务凭据；运行环境写入原来仅要求调用处于 running | 续租补充调用状态、期限、应用授权检查；运行环境和步骤运行关联绑定准确任务与租约。测试覆盖错误凭据、错误任务、跨工作空间、过期、取消及正常续租 |
| 成员做完工作，系统却保存不了执行进度 | 真实 HTTP → Loom → PostgreSQL 路径报 `could not determine data type of parameter $5`；检查点 SQL 的参数编号空缺 | 修正参数顺序。受控模型服务返回结果后，两个成员运行、检查点、汇合输出和重复请求均通过持久化回归 |
| 后续修改容易把能力执行再次放进基础层 | `base/capability` 同时包含流程执行和 JSON Schema 编译依赖；基础依赖门禁实际失败 | 整体迁入 kernel，更新所有调用者。基础层门禁恢复通过，未增加依赖例外；AGENTS 明确新归属和禁止转发别名 |

过期失败表示平台不再继续派发，不证明远程进程或外部操作已经停止。人工确认后的恢复和既有协作退出路径仍在；远程失联后的核对、停止确认与重新授权属于后续控制机制验收。

## 控制责任的实际完成度

| 控制项 | 本批已证明 | 仍需后续完成 |
|---|---|---|
| 重试 | Runner 遇到执行失败不自行重复派发；失效领取不能开始远程执行；过期租约不自动重新入队 | capability 与 teamrun 统一尝试所有权；外部结果未知时的核对及重派授权 |
| 超时 | 调用上下文的期限传至成员执行器；失效租约无法续期或写入运行归属 | 恢复后累计总期限，真实远程超时及停止回执 |
| 额度 | 既有步骤计数检查点恢复正常写入 | 物理尝试用量归属、父子汇总、执行前额度分配及各运行时硬限制。步骤完成后计数不能被表述成资源消耗的硬保证 |
| 取消 | 数据库取消意图传播到执行上下文；迟到结果不能覆盖取消；取消后拒绝续租和运行关联写入 | 远程停止确认、不可撤销外部影响及产品中的状态表达 |
