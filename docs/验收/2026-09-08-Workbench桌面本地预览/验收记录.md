# Workbench 桌面本地预览验收

2026-09-08。本记录对应独立分支 `codex/workbench-desktop-parallel-plan` 的原生预览与共用 UI 微调。代码基线为 `1734f77`，最终改动和验证证据随本记录提交。

桌面随应用打包现有 Workbench 前端，提供原生窗口、菜单、右键编辑、连接设置、下载和窗口恢复。网页版共用侧栏、输入框、首页及工作现场图标，图标保留状态角标、悬停与键盘提示。组件与操作仍由原包维护。

完整运行方式、当前实现和限制见[桌面 README](../../../workbench/apps/desktop/README.zh.md)。桌面中的会话使用既有浏览器夹具，两台回环服务只验证连接、实例与下载。账号认证、Host 传输、MCP、材料派发、真实模型和执行结果均未接入。此记录不将 T03 预览等同于 G01–G20 或 S1–S3 完成。
