结果：CSV、TSV、SVG × 1440 / 390 视口的六种组合通过。人工检查基础截图及图纸放大截图，下载与缩放可见，无页面横向溢出、重叠或控件截断。组件内部阅读宽度分别为 998 / 356 px；此处没有复刻 Workbench 侧栏与外层面板。

- TSV 使用 201 行 × 41 列输入，实际呈现 200 行 × 40 列，并显示截断说明。
- 需要横向阅读的表格，以及放大至 200% 的 SVG，使用原生横向滚轮和键盘左箭头验证滚动；焦点边框可见。
- 同一 SVG 在测试容器隐藏后再显示，保留 200% 缩放与横向位置；适应宽度回到 100%；切换文件重置为 100%。此项证明组件本地行为，生产跨页签是否保持挂载另由主流程验收。
- 六种组合均传入下载入口参数并检查可见；未测试真实鉴权下载服务。
- SVG 图纸为人工生成样本，不能代替真实运行中 SVG 成果链路的验收。
