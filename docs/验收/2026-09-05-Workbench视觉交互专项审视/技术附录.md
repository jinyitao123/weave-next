# 技术附录与验证边界

本附录供后续实施定位。用户可先读[审视结论](审视与整改方案.md)和[样板方案](精修样板方案.md)。这里的实现依据不应原样出现在产品主界面。

## 产物预览支持矩阵

| 类型 | 当前实现可确认的能力 | 本轮真实页面验证 |
|---|---|---|
| Markdown | 按标题、段落、列表、表格等渲染 | 已读取历史阶段文档，含长表格；见 A11、A13 |
| HTML | 独立静态预览，固定520像素高；脚本及外部资源受限 | 未验证真实文件的版式与滚动 |
| CSV／TSV | 表格预览，最多200行、40列；有限制提示；无专门表头处理与固定表头 | 未验证真实文件的显示效果 |
| SVG | 图片显示，50%—400%缩放、重置、加载及失败提示 | 未验证真实图片及缩放效果 |
| 纯文本／JSON／YAML／XML | 保留换行的文本兜底，不是专用结构化查看器 | JSON终审批注已看，见 A18；其余未逐类验证 |
| PNG／JPEG | 当前成果阅读器没有专用图片分支 | 未验证真实文件回退效果 |
| PDF／Word／Excel／PPT | 没有对应文档、工作表、幻灯片阅读器 | 未验证真实文件回退效果 |
| 音频／视频及其他二进制 | 没有专用播放器或阅读器 | 未验证真实文件回退效果 |

有文件类别名称或下载链接，不等同于支持在线预览。HTML预览是静态受限页面，不等同于可运行原站点。CSV预览不等同于Excel工作簿支持；SVG不等同于所有图片格式支持。

代码还显示，会话工具卡的文件预览截取前12,000字符并以文本呈现，未复用现场格式阅读器。同一文件跨入口的效果差异本轮未逐一实测，列为后续核查项。

## 展开与阅读状态的证据边界

- 已实测：成员内层展开及scrollTop=460保留，外层scrollTop从254.5变为0，正文位置下移254.5像素。见 tab-reading-return.json。
- 已实测：阶段文件展开后切进展再回成果，外层阶段分组变为收起。见 A21、A22。不能因此说所有文件展开状态都丢了。
- 源码确认但未浏览器复现：收起文件会卸载内容；SVG缩放是内容组件的本地状态，表格和图片滚动未接入统一记忆。需要真实文件复验后才可给效果结论。
- 已实测：方向键切成果后焦点为BODY，下一次Tab进入页签之前的“查看任务要求”。见 keyboard-tab-focus.json。
- 源码解释：两种分支分别渲染页签，按键处理先选择再聚焦旧引用；替换分支后旧DOM移除。外层阅读漂移的具体浏览器机制未下定论，修复应验证用户看到的锚点而非只验证内部数值。

## 独立复核与资料来源

主 Agent 负责全部真实浏览器操作、截图和测量；视觉 Agent 复核层级与控件语言；交互 Agent 只读追查状态与格式能力；独立复核 Agent 检查优先级及证据边界。报告统一保留“已实测”“源码支持”“未验”三种结论，避免把代码分支当作用户体验通过。

Apple Scroll views 与 Layout 的正文依据由官方域名搜索结果取得；直接打开页面返回JavaScript壳。Focus and selection只取得官方索引摘要，未作为详细正文规范援引。具体像素、时长、重复次数均为本项目样板建议。

本轮没有修改产品代码，没有运行构建或功能测试来替代视觉审视。当前工作区原有改动保留。审视开始与结束的已跟踪差异摘要比对记录另存为 source-integrity.json；该摘要不能证明外部环境与未跟踪文件完全无变化。
