# 日冕计划 · 任务背景与工作纪要修订稿

**修订日期**　2026年8月20日  
**文件状态**　任务概念与先期论证基线  
**适用范围**　国内请示、国际工作层沟通和后续专家论证

## 一、任务定位

日冕计划研究文明信息与生物样本在超长时间尺度上的异地保存问题。现阶段尚不具备批准整船研制、轨道建造和载人发射的工程依据。当前任务应限定为先期论证，先回答任务边界、基本物理、关键技术成熟度和成本数量级四组问题。

长期任务存在三条可分离的路线。

1. 激光光帆先锋探测器。目标是获取邻近恒星环境数据，验证星际通信、导航和高速微型飞行器技术。
2. 无人文明档案载荷。目标是长期保存知识、基因信息和可验证的解码说明，运输方案另行论证。
3. 载人星际飞行器。该路线依赖推进、封闭生态、辐射防护、在轨工业和长期社会治理等多项尚未成熟的能力，只能作为远期研究对象。

三条路线可以共享研究成果，但不得用克级探测器的可行性替代百万吨级载人飞行器的可行性。

## 二、经复核的物理基线

### 1. 航行时间与任务终点

比邻星距太阳约4.25光年。按0.03倍光速匀速巡航，单程飞行约141.6年。该数值尚未计入加速、减速和航向修正。若任务要求进入目标恒星系统并驻留，还需要与加速同量级的减速能力。后续文件必须分开使用“飞离太阳系”和“抵达目标恒星系统”两种表述。

### 2. 动能下限

把100万吨质量加速到0.03倍光速，飞行器自身最低动能约为4.05×10²²焦耳。若按500万吨入轨物资作同样计算，下限约为2.02×10²³焦耳。两项数值都没有计入发动机效率、排气动能、推进剂、减速、备用和建造损耗，不能直接用作工程能源预算。

### 3. 人工重力

旋转半径1千米、转速2转每分钟时，外缘向心加速度约为43.9米每二次方秒，相当于4.47倍地球重力。若在同一半径取得1倍地球重力，转速约为0.95转每分钟。舱体半径、转速、允许重力和人体适应性应作为联合设计变量。

### 4. 高速尘埃撞击

1毫克尘埃以0.03倍光速相对撞击时，动能约为40.5兆焦，约等于9.7千克TNT当量。10毫克尘埃的动能约为405兆焦。原纪要所写“1毫克约450兆焦”已撤回。防护方案需要给出尘埃通量、粒径分布、盾体面密度、间距、消耗率、补充方式和总质量。十千米级鞭普尔盾列只能保留为待评估概念。

### 5. 多目标机动

按公开天球坐标计算，比邻星与巴纳德星方向相隔约78度，比邻星与鲸鱼座τ相隔约101度，巴纳德星与鲸鱼座τ相隔约117度。在保持巡航速度的理想条件下，10%至15%的速度增量只能支持约5.7度至8.6度的转向。现有速度增量无法支持三个目标之间的中途切换。目标选择应在主加速前完成，航程中的速度增量主要用于小角度修正和避险。

### 6. 先锋探测器回传时间

探测器按0.2倍光速飞往比邻星，最低飞行时间约21.2年，数据返回地球还需要约4.25年。即使在计划批准当天发射，最早回传也约需25.5年。考虑系统研制和部署，真实时间更长。先锋数据不得作为第20年以前的母舰决策条件。

## 三、技术成熟度边界

### 1. 推进

脉冲聚变推进仍处在概念、建模和部件研究阶段。当前聚变研究普遍把氘氚反应视为最容易实现的燃料路线。氘氘、氘氦3和脉冲裂变聚变方案可以进入比较研究，现阶段不指定主案。先期论证需要统一比较有效排气速度、推力、脉冲频率、增益、燃料循环、中子损伤、散热、维护和推进剂质量比。

### 2. 封闭生态

现有空间生命保障系统仍需要补给和更换部件。地面封闭生态试验可以验证局部循环和控制方法，三年缩比试验不能直接证明万人系统可运行一百年以上。验证计划应分级扩大规模和连续运行时间，并纳入故障恢复、污染控制、遗传多样性和工业备件循环。

### 3. 人体冬眠

长期人体冬眠尚无可用于载人航天的成熟方案。后续质量、空间和补给估算不得以5000人冬眠为基线。冬眠研究可以作为机会技术单列，不得成为任务成立的必要条件。

### 4. 长期可靠性

推进、生态、计算、储存和结构系统都必须允许诊断、隔离、维修和再制造。原设想中“连续工作且无法大修”的发动机要求不宜继续保留。百年以上任务需要可更换模块、备件生产能力和失效后的降级运行方案。

### 5. 文明档案

石英存储、DNA样本、种子和微生物群落可以分别研究。长期档案还需解决校验、解码说明、读取设备再制造、版本迁移、样本复苏和行星保护。任何单一存储介质都不能直接等同于完整文明备份。

## 四、组织与先期论证方案

建议组建25至30人的核心筹备组，并通过课题制调用外部机构。核心组包括系统工程、推进与能源、生命保障、轨道与结构、任务科学、成本评估、法律治理和文档配置管理人员。首席否定官和独立成本评估职能继续保留。

先期论证周期建议为18至24个月，形成以下成果。

1. 任务需求文件和运行概念，明确飞离、飞越、进入目标系统和驻留等任务终态。
2. 质量、能源、速度增量、推进剂、功率和散热预算。
3. 目标选择、轨迹、加速与减速方案，以及先锋探测器独立时间表。
4. 推进、生态、防护、在轨建造和长期维护的技术成熟度评估。
5. 工作分解结构、风险登记册、独立成本估算和年度现金流范围。
6. 国际合作可分工项、数据共享规则、出口管制和长期治理议题清单。

## 五、经费处理原则

原稿提出的2.4万亿元至3.4万亿元主案总投资缺少完整质量模型、推进模型和工作分解结构，暂不作为报批依据。原经费结构各项最低占比合计107%，最高占比合计125%，已经撤回。

先期论证经费应按课题包、试验设施、人员、独立评估和预备费自下而上测算。整项工程总成本只在任务架构、质量规模和推进路线通过独立评审后估算。阿波罗计划等历史项目可以用于说明治理和动员方式，财政占比必须采用相同分母和相同统计范围后再比较。

## 六、阶段决策门

1. 第六个月完成物理与任务边界审查。质量、能源、速度增量、目标几何和时间线必须互相闭合。
2. 第十二个月完成候选架构比较。每条路线给出成立条件、主要缺口和终止条件。
3. 第十八至二十四个月完成独立评审。通过后才能申请进入关键技术预研，未通过的路线停止扩大投入。

原稿中的第8年、第20年、第35年和第40年决策门不再作为当前承诺，仅保留为远期规划假设。

## 七、文书口径

国内请示只申请开展任务概念与关键技术先期论证，不申请整船立项，不引用未经闭合的总投资。

英文Non-Paper只试探各方参与先期研究的意愿，讨论研究分工、数据共享和治理原则。文件不提出整项工程成本分摊，也不承诺40年内建成载人星际飞行器。
