# 桌面外壳接入设计

## 窗口与能力

候选 Electron 主进程拥有连接选择、非敏感偏好和下载协调，远程内容继续使用同一 Workbench Web 页面。远程页不获得 Node、任意文件、shell 或通用 IPC 调用能力。窗口配置需显式关闭 nodeIntegration，启用 contextIsolation 和 sandbox，并保留 webSecurity；窗口导航、弹窗与外部链接由主进程按当前服务校验。以上机制依据 [Electron 官方安全文档](https://www.electronjs.org/docs/latest/tutorial/security)，尚未在本项目窗口中验证。

连接设置由受信的本地壳层发起。ConnectionSelection 调用描述与认证适配器，成功后才保存并激活候选；切换开始后旧页面响应不再更新当前状态。候选登录必须使用独立的临时会话状态，失败或取消不能改变此前活动账号，迟到响应也不能重新安装 cookie。描述/认证成功但偏好保存失败时，适配器负责丢弃候选会话。

## 服务分区与生命周期

依据 [Electron session 文档](https://www.electronjs.org/docs/latest/api/session)，主进程应为服务选择明确分区，不能让不同服务共用默认会话。实际分区名从受信的规范化 origin 派生；账号身份与实例变化仍要由后续认证设计处理，不能仅靠分区名声称账号隔离。

仅当前活动页面拥有业务订阅。关窗销毁本地窗口和观察资源，保留已记录的服务选择与原操作身份；重开后读取原服务事实。退出账号应先让本地响应范围失效，再撤销账号会话并清理对应业务缓存。用户下载文件保留。这里不新增 run 恢复、取消或重派发逻辑。
