# 桌面并行准备验收步骤

本文件区分已执行的客户端夹具测试与后续真实业务验收。自动夹具由 [fixture-service.ts](../../../workbench/apps/desktop/tests/fixture-service.ts)维护，仅监听回环地址和系统分配端口，只处理 `/fixture/describe` 与 `/fixture/authenticate`，不使用真实账号、token、Session、run 或数据库。测试完成时关闭自身监听器、释放等待并删除自身临时偏好目录。

## 已执行的客户端行为

[connection-selection.spec.ts](../../../workbench/apps/desktop/tests/connection-selection.spec.ts)覆盖首次默认、用户覆盖、重启/安装默认值变化、偏好文件重载、非法地址、损坏配置、描述与认证失败、写入失败、取消不响应中止的适配器、迟到成功/失败、A→B→A、对象替换、断开/关闭、实例变化及实际 HTTP 断线。每个异常都核对偏好或页面可用性；不会仅检查没有抛异常。

完整逐例结果见 [connection-tests.json](connection-tests.json)。这些测试只部分覆盖 G02/G15/G16 的客户端责任；G01–G20 的真实出口均未因此标为通过。严格类型检查、静态检查、已有 Workbench 构建/测试和范围检查的结果单独记录在[执行记录](执行记录.md)。

## 真实接入后的操作与证据

所有下列真实场景初始状态均为“未执行”。执行时使用独立账号代号、专属 Host/卷、隔离 Runtime 与材料副本，保存准确 SHA、软件包摘要、操作身份、实际响应和成果摘要；凭据不进入证据。

| G 用例 | 操作 | 必须留存的可核对证据 |
|---|---|---|
| G01/G02 | 干净目标设备安装，登录预置服务；改服务后重启/升级，再制造候选失败 | 安装物摘要与系统版本；真实登录身份；重启前后偏好；失败后原连接保留 |
| G03/G04 | 同用户从 UI/MCP/API 操作后降权；设备 A/B 登录，A 产生待提交操作后退出 | 三入口实际 actor 和结果；A 来源新写入被阻止、B 自身操作仍符合权限的记录 |
| G05/G06 | 分别在接收前、持久接收后、Weave 接受后断开或强杀 Host，并以原 ID 重试 | 三类回执的持久顺序；同 ID 同内容返回原事实，不同内容冲突；实际业务写入数量 |
| G07 | 让服务端提交成功而响应丢失，再断网、重开、切服务 | 原服务查询与原 ID；不向新服务提交旧操作；实际 run 数量，而非客户端发送次数 |
| G08 | A/B 两账号各用独立 Host，尝试引用对方对话、材料、导出与设置 | 个人/共享政策及实际拒绝或允许结果；独立卷与身份，不靠“ID 很难猜” |
| G09/G10 | 上传真实文件并由异机 Runtime 读取；复用同一请求键但改变材料集合 | 上传、派发快照和 Runtime 字节摘要；材料改变时冲突；不使用共享客户端路径 |
| G11 | 节点在线但缺能力或资源；监督模型不可用 | 真实就绪判断与页面阻断；不将健康探针当可执行证明 |
| G12/G13 | 关窗后等待 run 结束；重启 Host 后重新打开原对话 | 同一个 run 的对账过程、可打开成果、无重派发；未恢复旧 Agent 的新写入 |
| G14 | 暂停旧 Host，尝试启动替代者，再恢复旧进程 | 独占卷写者证据；不能证明旧进程退出时，替代启动被拒绝 |
| G15/G16 | 描述通过后更换服务实例；切服务时让旧认证、续期、上传和订阅响应迟到 | 服务器入口拒绝旧 expected instance；当前页面与 cookie 不被污染；旧操作回执仍归原服务 |
| G17/G18 | 对应平台安装/更新、中文输入和下载取消/失败；旧数据迁移和降级 | 干净设备录像或截图、签名拒绝、偏好保留、备份恢复与无双写证据 |
| G19/G20 | 丢弃投影缓存；分别停前台 turn 与业务 run；检查实际 HTTP/MCP 路径和依赖 | 权威事实重建；不同停止对象对应不同回执；没有新增业务控制器或反向依赖 |

## 执行闭环的对照反例

原修复的业务反例继续由其证据目录维护。桌面接入时只消费同一条业务事实，再对照以下展示结果：正常结束但缺必需成果时不显示核验通过；模型称 PASS 但证据未知时保留未知；有额外错误外部写入时不总体通过；用户采用或要求修改不覆盖执行事实。旧输入/旧修订换新请求键的拒绝，以及 CLI/Loom 的取消、预算和接续，必须由真实入口证明，不能用本夹具评分替代。
