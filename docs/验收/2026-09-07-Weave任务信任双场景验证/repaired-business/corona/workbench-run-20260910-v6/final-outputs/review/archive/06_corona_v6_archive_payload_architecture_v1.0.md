## 0. 结论速览

1. **任务语义已由冻结基线决定**：路线 B 是**多代/档案/信标型**目标，而非近端回报目标。`0.01c–0.05c` 下到比邻星 4.25 ly 需 **85–425 年**（**`TIME_ALPHA(S-0.05c)=85 yr`** / **`TIME_ALPHA(S-0.03c)=141.667 yr`** / **`TIME_ALPHA(S-0.01c)=425 yr`**，frozen derived）。速度轴**不改变**「档案星际送达是多代目标」这一语义，只改变**航时与暴露窗口**。
2. **架构的第一性要求**：一个**无人、无维护、无电源刷新**、需跨越 **85–425 年**的档案载荷，其**主存活层必须是被动、辐射免疫、零耗电**的介质。数字固态/磁介质在无主动刷新下**必然退化**（见 `07` §3 计算：NAND/磁带在 85–425 年单副本存活概率 ≈ 0.000–0.18），**不能**作为主存活层，只能作为**高密度纯增量层**。
3. **本节点推荐的双介质架构**：「**传世层（enduring）** + **完整层（corpus）**」双层（详细见 §3）。传世层保证「文明核心」跨越世纪；完整层用**极高冗余 + 纠错编码**保证「全部语料」尽最大可能完整。
4. **最大未知风险**：尘埃/微流星体通量在 `0.01c–0.05c`、85–425 年暴露窗口下**缺直接证据**（表 `07` §6），是超越辐射折寿的主导未知项；本节点**不明知设计**，建议**先导载荷测量**（详见 `07` §6），且**不**声称任何「已证实可存活」。
5. **对负责人级判定矩阵的印证**：速度轴澄清了路线 B 的「被动载荷 vs 独立近端档案任务」分工位。本文件把两种构型（**搭载型 / 独立型**）都给出，并把选择权交还 systems-architect / 治理评审（`01` §4 标记为「需治理/伦理校核」），本节点不越域替判。

## 1. 任务语义与速度轴影响

### 1.1 冻结语义（引用，不重定义）

- **P2（frozen）**：三种速度到达另一颗恒星需 **85–425 年**，均超出单次任务尺度；「星际抵达」在这些速度下**不是**近端回报目标，而是**多代/档案型/信标型**目标。
- **B × 速度（frozen §4）**：B 在 0.01c 为低速长航时载荷，承担多代「信标/档案」语义；0.03c 同左、航时缩短；0.05c 随 CS-3 探针更快到达前驱；档案「星际送达」仍为多代。
- **关键转折点（frozen §4 B 行）**：速度轴澄清档案是**被动载荷**还是**独立近端档案任务**；多代语义需**治理/伦理校核**。

### 1.2 速度轴对**档案载荷设计**的直接映射（本节点分析）

| 情景 | 到比邻星航时 `TIME_ALPHA` | 到太阳引力透镜/前驱航时可用性 | 对档案载荷的影响 |
|---|---|---|---|
| **S-0.01c** | 425.0 yr | 到达前驱慢（数月–1.6 年，frozen P1） | 档案可承担**独立近端档案信标**；星际送达为多代 |
| **S-0.03c** | 141.667 yr | 到透镜区约 106 天、前驱约 6.3 月（frozen §4 A 行） | 折中：既可近端广播，也可多代送达 |
| **S-0.05c** | 85.0 yr | 覆盖最快 | 单独随探针更快到达前驱；星际送达仍多代 |

> **结论（本节点）**：速度轴主要改变**近端信标/广播窗口的时间尺度**与**星际到达的世代数**，而不改变「档案必须能被动存活 85–425 年」这一**架构约束**。三条速度下**采用同一套双介质架构**，仅**冗余级别（K、N）与屏蔽裕度**随航时/暴露窗口调整（见 `07` Table E）。

## 2. 载荷定位与两种构型

### 2.1 构型 A「搭载型」（hitchhiker）
档案作为**路线 A（激光光帆先锋探测器）或路线 C 母船**的**子载荷/副载**，本身不独立推进。
- 优点：复用推进/结构/TT&C；档案文件纯被动，不占推进预算。
- 缺点：到达终点与信标窗口依赖母体；母体失控则档案可能滞留（需独立分离机制）。
- 适用：0.02c–0.05c 把档案「捎带」到前驱/日球层近端，做近端广播。

### 2.2 构型 B「独立型」（standalone near-end archive）
档案作为**独立近端档案/信标任务**，自带电源与信标，进入**太阳引力透镜区 / 1000 AU 前驱区**后**就地广播**或持续存在。
- 优点：不依赖母体；可作为多代「文化脉冲」（beacon）持续回传/广播；独立故障隔离。
- 缺点：需自带电源/北向发信，质量与成本增加；生命周期管理复杂。
- 适用：0.01c–0.03c 的**近端档案信标**定位。

### 2.3 接口（交还裁决的信号，本节点不替判）
两种构型的**选择**属于 systems-architect（任务架构）与**治理/伦理**（多代语义）职责。本节点给出**两种构型都适用的载荷架构**（§3），并在 `07` 独立计算两者差异（供电需求、信标功耗、寿命曲线）。**冲突时以专业证据为准、写明冲突点**（`04` §5 接口消解规则），不默默覆盖基线。

## 3. 双介质载荷架构（分层）

### 3.1 架构总览（五层）

```
 L1 内容/策展层    what to preserve        -> 文明核心（传世） vs 全部语料（完整）   [治理/伦理]
 L2 编码/可读层    how to decode           -> 通用罗塞塔 + 自描述元数据 + 冗余编码 + 物理读数键
 L3 物理存储层    where it is stored       -> 传世层(模拟蚀刻) + 完整层(数字高冗余)   [本节点]
 L4 载荷总线层    bus/power/thermal/rad    -> 供能 / 温控 / 屏蔽(Whipple) / 指向 / 分离 / 生物密封
 L5 集成接口层    integration with carrier -> 搭载型(接 Route A/Sail B) 或 独立型(自带总线)
```

### 3.2 各层职责与本节点相关度

| 层 | 职责 | 本节点输入 | TRL 口径（frozen §3，B 约 4–6） |
|---|---|---|---|
| **L1 内容** | 决定「留存什么」；文明核心 vs 完整语料；治理/伦理校核 | 只提**容量/分发**需求，不擅定内容 | 内容层为方案问题，TRL 不适配 |
| **L2 编码** | 保证「无论谁拿到都能读」：物理/原子学共同语言 + 自描述 + 纠错编码 | 定义**编码冗余/校验/断链可恢复**要求 | 概念级，TRL 低（需研发） |
| **L3 物理存储** | 实际承载信息；**主存活层**（本节点核心） | **最优先** | 传世层部件 TRL 8–9（Voyager 类蚀刻/flown），完整层集成 TRL 4–6 |
| **L4 总线** | 供能/温控/屏蔽/指向/分离/密封 | 定义**寿命/无维护/屏蔽/容差**要求 | 长寿命无维护系统非全流程飞行验证 → 系统 TRL ≤ 4–6 |
| **L5 集成** | 与载体/母体或独立总线对接 | 定义接口、包络、质量、分离 | 接口工程，TRL 4–6 |

> **诚实点（本节点明确）**：路线 B 的**部件**（蚀刻、光存、固态、屏蔽材料）多为高 TRL/商用；但其**作为「85–425 年无维护星际档案」的整机**并未经飞行验证。因此**组件 TRL ≠ 系统 TRL**；路线 B 整机按 frozen §3 仍为 **TRL 4–6（概念级）**。

### 3.3 双介质栈（L3）：传世层 + 完整层

| 层 | 介质候选 | 被动保留期 R（assumption，需核验） | 辐射敏感 | 数据密度 | 存活角色 |
|---|---|---|---|---|---|
| **传世层（端到端守护）** | 模拟蚀刻金属/类钻石/硅蚀刻（Voyager 金唱片类 + 现代微蚀刻） | 名义 1e6 yr（assumption） | **辐射近免疫** | 低 | **主存活层**：保证核心信息跨 85–425 年 |
| **完整层（高密度语料）** | 高冗余数字（Rad-Hard 固态 / M-DISC 单次刻录 + 纠错码） | 30–300 yr（assumption，需核验） | 敏感（TID） | 高 | **纯增量层**：靠 K-of-N + ECC 抗退化 |

**设计逻辑**：
- **传世层承担「零维护」语义**。因为 85–425 年 > 任何需主动刷新的数字介质生命周期，唯一能**无电、无刷新**跨越世纪的介质是**模拟物理蚀刻**。它把「文明核心」（语言 / 科学基本事实 / 时间与坐标 / 人类形象 / 一组可复现解码与测量方法）以辐射近免疫方式固化。
- **完整层承担「尽最大可能完整」语义**。用**极高冗余 + 纠错码**（见 `07` Table E，K-of-N）弥补数字介质被动退化；接受其在无刷新下质量递减，但通过冗余把**整库可恢复概率**抬到设计目标（P≥0.99，见 `07`）。
- **双层互为备份**：传世层提供「核心必然存活 + 可读性」；完整层提供「覆盖尽可能广」。任何一层失效都不至于全损。

> **禁止事项（frozen `forbidden_claims` 列表，本节点不触碰）**：不得作出任何「施工就绪 / 制造就绪 / 飞行认证 / 整项目成本已承诺」类结论（即基线 `forbidden_claims` 中的四类表述）。本文件全部为概念级。

## 4. 载荷总线（L4）对档案可靠性的关键约束

| 子系统 | 本节点可靠性要求 | 备注（量级/假设） |
|---|---|---|
| **供电** | 传世层**主存活 = 零耗电**（无电源）；完整层/信标供电需覆盖任务窗 | 独立型信标需长寿命（RTG 或自消亡后停止）；量级为假设 |
| **热控** | 介质温度稳定在存档标称窗口（超温折寿） | 被动散热/隔热为主 |
| **辐射屏蔽** | 累计 TID 预算（见 `07` §2：85–425 年累积 12–85 Gy，屏蔽示意） | 铝当量 0–30 g/cm²，GCR 简化模型 |
| **微流星/尘埃防护** | Whipple 缓冲/多层；**通量=unknown**，无法定量 | `07` §6，需先导测量 |
| **指向 / 信标** | 近端广播需指向（若无信标传世层免指向） | 独立型才需要 |
| **分离 / 密封** | 母体失控时需独立分离；生物/污染控制（Planetary protection） | 接口工程 |
