## 0. 图纸定位与硬性前提

1. **全部为「概念级」图纸**：只表达**架构、布局、功能关系与量级**，不表达可制造/可飞行细节。

3. **速度轴贯穿**：概念图涉及航时/边界时必须三情景齐备或显式标注当前情景 ID，**不得残留单 0.03c**。

| **Fig B-02** | 传世层（端到端守护）模块 | `06` §3.3；`07` AR-02 | 模拟蚀刻核心、物理读数键/罗塞塔、密封、辐射近免疫示意 |
| **Fig B-03** | 完整层（高密度语料）+ K-of-N 冗余 | `06` §3.3；`07` §4 | 存储介质、纠错编码、**N-of-K 副本**与校验/对账逻辑 |

## 3. 统一标注规范（强约束）

每张 SVG/OpenSCAD 的标题区（或图边）必须包含**全部**字段；缺一即视为不满足图纸需求（`08` 为 drawing 需求）：

| 字段 | 固定值 / 格式 | 说明 |
|---|---|---|
| `baseline_id` | `corona-prephase-a-v1` | 与冻结基线一致（gate 10） |
| `baseline_version` | `1.0.0` | 版本一致 |
| `scope` | `Level-0 / Pre-Phase A conceptual` | 范围标注 |
| `figure_id` | `Fig B-01`…`Fig B-05` | 唯一图号 |
| `version` | 本图版本（如 `v1.0`） | 单图版本 |
| `date` | `2026-09-09` | 生成日期 |
| `scenario` | `S-0.01c / S-0.03c / S-0.05c` 或「三情景通用」 | **速度轴贯穿**，禁单 0.03c 残留 |
| `who` | `archive-reliability-designer`（需求方）/ `digital-engineering-builder`（drawing 方） | 需求↔绘制归属 |
| **免责** | 固定「**概念级 · 不可用于施工/制造/飞行认证**」 | 必须逐图出现 |

> **禁止**：不得在任何 SVG/OpenSCAD 中出现「施工就绪 / 制造就绪 / 飞行认证 / 整项目成本已承诺」四类表述（即基线 `forbidden_claims`）。

## 4. 概念级术语与量级纪律（图内文字）

- 图内**量级标注**（如航时、尺寸、质量、TID）必须与 `01`/`baseline` 一致，且**不得**把量级当精确设计值。
- 涉及**航时/暴露**时写全情景 ID（`TIME_ALPHA(S-0.05c)=85 yr`），不得只写「0.03c」。
- **未知项用 `unknown` 明示**（如尘埃通量），不得用假设值代替（`07` §6）。
- 图内不得出现「可施工/可制造/可飞行」等承诺性表述。
