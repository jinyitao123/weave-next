## 2. 各路线成立条件 → 关键缺口 → 终止条件

### 2.1 激光光帆先锋探测器（laser_sail_precursor / A）

- **成立条件**：地面激光阵列能以克级光帆质量、在中程被加速到 0.2c；克级载荷集成可行；0.2c 回传时间线（21.2 yr + 4.25 yr ≈ 25.5 yr）可接受；高速尘埃生存可接受。
  - 关键缺口：推进效率、帆材料损失/耐热、尘埃通量/盾体、克级载荷集成（均 `unknown`）。
  - 速度轴注记：0.01c/0.03c/0.05c 下束功率门槛随速度降低而降低（0.2c 锚点降 16–400 倍，`derived_result`），**降低**先导可达性门槛，但不改变成立条件的本质。
- **终止条件（出现任一，即停止扩大投入）**：
  | # | 终止判据 | 依据 |
  |---|---|---|
  | T-a | 地面激光阵列在可行功率尺度下无法把克级载荷加速到 ≥0.2c，或单位能流密度下帆无法存活 | `assumption` |
  | T-b | 高速尘埃/星尘环境使克级帆无法在到达前存活（盾体+消耗率不可行） | `unknown` |
  | T-c | 数据回传时间线使得「先锋数据作为第 20 年以前母舰决策条件」不可能（背景纪要 §二.6） | `derived_result` |
  | T-d | 克级探测器的**单位科学成本**明显高于替代手段（如近距望远镜/原位探测器），且无不可替代科学价值 | `assumption` |
  | T-e | 该路线结论被用于证明大型无人载荷/载人飞船可行（跨路线外推），触发事实纪律红线 | `verified_fact` |

### 2.2 无人文明档案载荷（uncrewed_civilization_archive / B）

- **成立条件**：存在**单一或组合存储介质**可支持跨百年读回 + 可验证解码 + 版本迁移 + 读取设备再制造 + 样本复苏；行星保护协议可满足。
  - （运输方案另行论证，故成立条件不依赖运输。）
  - 关键缺口：读回/再制造/迁移/复苏未验证；单一介质 ≠ 完整文明备份（`unknown`）。
- **终止条件（出现任一，即停止扩大投入）**：
  | # | 终止判据 | 依据 |
  |---|---|---|
  | T-a | 没有任何存储介质能在合理预算内演示**百年级**读回 + 校验 + 迁移 | `unknown` |
  | T-b | 读取设备再制造 / 版本迁移 / 样本复苏无法在长期尺度闭环 | `unknown` |
  | T-c | 行星保护 / 污染控制 / 返回后失效协议无法达成（把潜在污染风险当作未知项锁死） | `assumption` |
  | T-d | 档案只能作为「记忆展示品」而非「可验证文明备份」，无法满足档案任务目标 | `assumption` |

### 2.3 载人星际飞行器（crewed_interstellar_vehicle / C）

- **成立条件**：推进、封闭生态（万人×百年）、辐射防护、冬眠/生命保障、长期可靠性与再制造、在轨工业、多代际治理**全部**使能项闭合。
  - 关键缺口：上述多数为 `unknown`/`assumption`，轨道尚远（背景纪要 §一：只能作为远期研究对象）。
  - 速度轴注记：0.01c–0.05c 下往返均 ≥85 年单程（`derived_result`），**强化**「不可承诺时间表」结论。
- **终止条件（出现任一，即停止扩大投入）**：
  | # | 终止判据 | 依据 |
  |---|---|---|
  | T-a | 任一**必需要使能项**（封闭生态规模化 / 星际辐射 / 寿命支持 / 推进规模 / 长期可靠性 / 在轨工业 / 治理）在 Pre-Phase A 内无法闭合到成立阈值 | `assumption` |
  | T-b | 该路线的动能下限数量级显示无可信能量的来源（如 0.05c→1e23 J 远超可行能源）且无替代能量路径 | `derived_result` |
  | T-c | 把 5000 人冬眠 / 万人百年生态作为成立基线，违反了「冬眠不作必要 / 三年缩比 ≠ 万人百年」的事实纪律 | `verified_fact` |
  | T-d | 克级光帆可行性被用作载人可行性证据（跨路线外推） | `verified_fact` |
