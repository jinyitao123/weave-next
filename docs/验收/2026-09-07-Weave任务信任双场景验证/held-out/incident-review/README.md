# 第三保留样本：服务事件复核

本样本用于检验已发布交付合同能否在未见业务中随团队冷启动、自然语言派发和实际交付冻结。它不用于替代电商或日冕业务验收。

执行前冻结 `team-template.yaml`、`task.txt` 及其 SHA-256。派发后遵守以下停手规则：

1. 不修改生产代码、团队模板、任务正文或交付合同。
2. 不提交运行纠偏，不补充路径，不恢复或替换团队成员。
3. 不因结果失败调整验收标记或重新派发；失败按真实失败记录。
4. 只允许读取运行状态、交付报告和最终文件，并独立复算三项算术。
5. 机器交付通过不代替用户采纳；用户评价保持独立。

该样本只能证明冻结合同链路和一个冷启动文本文件任务的泛化切片，不能证明日冕增量恢复、成员级纠偏半径或广泛业务泛化。
