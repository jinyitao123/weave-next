# 修复后第二保留样本：库存批次复核

本样本在 runtime 引擎认证就绪判断和团队模板 runtime 回退修复部署后冻结。它验证新团队是否绑定到可认证的引擎，并通过 Workbench 完成自然语言团队名派发、真实成员执行和已发布合同交付核验。前两个失败样本保持关闭，不回填也不重跑。

执行后遵守以下停手规则：

1. 不修改生产代码、团队模板、任务正文、交付合同或启动配置。
2. 不补充团队 UUID，不提交运行纠偏，不补路径，不恢复或替换成员。
3. 不因结果失败调整验收标记或重新派发；首个结果按真实结果记录。
4. 只读取运行、交付报告和最终文件，并独立复算三项算术。
5. 机器交付通过不代替用户采纳，用户评价保持独立。

该样本只判断修复后的认证 runtime 选择、自然语言派发和发布合同链路，不证明日冕增量恢复、成员级纠偏半径、电商外部副作用或广泛业务泛化。
