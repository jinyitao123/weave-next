# 路径修复后保留样本：运输线路复核

本样本在交付合同路径身份修复部署后冻结。它验证新团队的认证引擎选择、Workbench 自然语言团队名派发、真实成员执行、`outputs/...` 合同路径映射、逐字内容条件和机器交付核验。前三个首结果保持关闭，不回填、不重查也不重跑。

执行后遵守以下停手规则：

1. 不修改生产代码、团队模板、任务正文、交付合同或启动配置。
2. 不补充团队 UUID，不提交运行纠偏，不补路径，不恢复或替换成员。
3. 不因结果失败调整验收标记或重新派发；首个结果按真实结果记录。
4. 只读取运行、交付报告和最终文件，并独立复算三项算术。
5. 机器交付通过不代替用户采纳，用户评价保持独立。

该样本只判断本次认证 runtime 选择、路径身份、内容条件和发布合同链路，不证明日冕增量恢复、成员级纠偏半径、电商外部副作用或广泛业务泛化。
