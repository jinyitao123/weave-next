|---|---|---|

| 并排查看与返回 | 默认对话/现场约 40/60，可拖动与键盘调整；窄屏先收导航；返回保留草稿、成员和阅读位置 | 待验 |
| 日常处理 | 不打开现场即可看当前待办、回答问题、重试和确认调整范围；受理与生效分别呈现 | 待验 |
| 成员与成果 | 输入、阶段与已保存成果能互相找到；点击具体名称展开对应文件；技术信息按需查看 | 待验 |
| 成果阅读 | Markdown 排版、CSV/TSV 单元格、SVG 缩放与静态 HTML 预览可用；预览截断不妨碍完整文件下载 | 待验 |
| 领取结果 | 原始材料到达实际执行成员；最终文件正文属于本次任务，缺文件时不显示已交付或采用评价 | 待验 |
| 项目进展 | 仅汇总明确关联的任务，排除无关和归档会话；团队、成员、待办与材料可回到原任务 | 待验 |

## 恢复与并发

| 场景 | 必须观察到的结果 | 状态 |
|---|---|---|
| 真实外部运行时断线 | 中断被定位到当前阶段；旧执行确认结束后才可重试；已完成成员与成果保留 | 待验 |
| 点击阶段重试 | 当前阶段重新执行并领取最终成果；队列与成员记录证明已完成成员没有重做 | 待验 |
| 响应丢失与再次断线 | 同一次操作重传只回放原结果；新一次失败需要新的用户操作，不能被旧请求自动重试 | 待验 |
| 重复点击与停止竞争 | 一个明确操作只处理一次；停止状态以执行退出回执为准；未确认停止不能标为已停止 | 待验 |
| 关闭页面与服务重启 | 回到同一工作与真实状态；旧响应不覆盖新任务、用户操作或评价；尚未送达的回执不冒充受理 | 待验 |
| 公开增量过程 | 真实 Codex 执行结束前已经看到公开内容；断线重传不重、不串成员；同一正文快照原位更新 | 待验 |
| 历史阅读 | 跟看时追随最新；上翻后更新不强制滚动，切换成员后保留阅读位置并可主动回到最新 | 待验 |
| 陈旧问题答复 | 旧问题已被其他入口处理后，旧表单不会回答后续新问题；原答复丢响应可重放同一结果 | 待验 |

能力边界仍须明确：静态 HTML 预览不等于应用已运行；文本与 SVG 文件获取不等于通用二进制存储；外部事实、工程计算、长期运维、公开执行隔离及真实采用率另需对应证据。

## 本轮实际发现

首轮归拢后，真实截图暴露主对话复用了完整现场面板，形成大块固定区域并挤占聊天；侧栏标题与状态同排截断，顶栏也会在并排时丢失任务标题。当前按用户反馈收紧主对话回执、将侧栏与顶栏分层，并依据实际视图状态显示全幅与返回操作。此轮视觉修正版须重新构建后查看真实页面，不能沿用先前构建的通过结论。

重载真实 Workbench 还发现：旧版本的未打开会话没有自动恢复工作任务投影，影响侧栏与项目聚合。修复采用仅针对声明需要列表恢复的投影、限定日志大小的只读恢复；超过边界则明确显示尚未读取，打开会话后加载完整记录，不把它当成普通已完成会话。

Go 最终源码于 04:54:34 UTC 通过带竞态检查和真实隔离 PostgreSQL 的 `make ci`；当前本机服务版本为 `23c6b1d-dirty+20260905-work-dialogue-0946d168`。构建与测试不替代上述跨进程验收项目。
