## 本版内容

- Workbench 统一承载任务对话、团队派发、工作现场、成员记录和成果查看。
- 成员执行配置与工作流原子发布，支持 Claude CLI、本机模型配置和备用模型策略。
- Claude 公开活动在执行中回传；排队、执行、已完成、停止待确认和记录不完整分别显示。
- 平台传递上游文件与来源信息，保留当前基线，并明确区分阶段产物和最终成果；支持 CJS、ASCII DXF 和内嵌渲染的 SVG 交付。
- 执行回执保存、重传和纠偏恢复具备幂等处理；服务重启后可复用已完成工作，避免重复执行。
- 任务卡、成员阅读、成果预览、键盘焦点和阅读位置已有一轮修复。

## 保留的边界

这轮验收有 Codex 监督：平台修复、OpenSCAD 安装和最终独立浏览器验收由 Codex 完成，专业成果由 Weave 成员执行并修复。不能据此声称团队全程无人介入。日冕成果为概念级论证；原始复跑脚本的一处验收输入仍引用本机路径，跨机使用需按交付说明配置。

工作现场后续的整体布局与细节精修从本版本之后开始，不包含在 v0.1.0 中。
