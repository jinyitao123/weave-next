# 代码仓库功能清理

用户明确要求剔除代码仓库功能线，并于 2026-10-21 授权继续完成。删除前只读核查本机 `weave`：活动仓库数为 0，绑定非空仓库的运行数为 0。

删除范围：管理端仓库页与仓库任务选项、代码变更/校验/PR/追问面板；对应专属 HTTP API、凭据代理、代码上下文冻结；Runtime Host 的自动克隆、检出、提交、校验命令和推送封装。移除代码任务专用协议字段及只验证这些功能的测试。

保留范围：普通任务提交、团队、执行节点、运行时工作目录、输入文件装配、普通输出与日志、运行证据导出、引擎通用工具权限、工作流通用编排及重试。不得删除通用能力来消除编译引用。

历史迁移文件与 `weave_environments`、`weave_run_code_contexts`、代码任务历史记录均保留；本次不删表、不清除凭据或既有运行数据。退休入口由路由回归确认不再可调用。产品、依赖与规模门禁在同一批次更新，删除所释放的预算不留作余量。

2026-10-22 补清：管理端运行失败原因中只由已删除的克隆、检出与代码交接产生的七项映射，以及工作区操作说明、团队开发说明和 MCP 入口说明里仍列出的"代码仓库""代码结果""发起代码任务""创建拉取请求"。这些文字会让模型和使用者以为该能力仍在。
