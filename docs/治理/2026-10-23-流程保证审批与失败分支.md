# 流程保证：人工审批与失败分支

## 来源

团队工作流图（`kernel/workflow/machine`）的解释器能执行人工等待、条件分支和失败路由，但团队草稿的受控修改只开放了串行、并行、汇合与交付。经 MCP 建队的智能体和管理端都无法把“必须经某人同意”“出错时按规定处理”落到流程上，只能写进成员的工作要求，由模型自觉遵守。

## 改动

受控修改新增四项修改。指南的“流程保证”（`guarantee`）类别只写入失败分支；审批照常接受，但不写入指南（见“审批暂不开放”）。

- `approval`：在负责人、成员执行（不在并行分支）或汇合步骤之后插入人工审批。编译为人工等待节点（`decision` 为 `approve`／`reject`，`comment` 必填）、条件节点和一个新的交付节点。只有 `decision` 为 `approve` 的条件分支通往原来的下一步；其他情况交付审批意见。
- `approval_remove`：按审批名称移除整组节点，恢复原连接。
- `on_failure`：为负责人或成员执行步骤设置失败分支。失败时由指定成员处理，处理步骤收到失败步骤原本收到的输入，处理结果单独交付。
- `on_failure_remove`：移除只能经该失败边到达的整条分支。

驳回语义由用户在 2026-10-23 选定：驳回时交付审批意见，运行以成功结束。另两个方案未采用：一是放宽 machine 校验、驳回即终止；二是只允许批准。

## 审批暂不开放

2026-10-23 决定：审批从 MCP 指南和入口说明中移除，代码和受控修改保留。指南改为如实说明“团队流程目前不提供人工审批保证”，并要求不要用成员的工作要求冒充审批。满足 #105 的两个前提后再重新开放：

- 审批人由服务端指定并强制执行；
- 驳回不以成功结束（重新评估“驳回即终止”）。

## 约束

- 设置了审批或失败分支的流程有多个交付，所以拒绝同时启用结果分类（`workbench_result_v1`）或业务回执完成检查，这两者都要求唯一交付。
- 由定时、接口、事件发起的流程不能设置审批（machine 第 9 阶段 `CodeSessionRequired`）。包含审批的流程不能发布为能力（`capability.ValidateWorkflowSource` 拒绝人工等待）。
- 设置失败分支后，这一步遇到可重试的基础设施故障也会走失败分支，不再进入运行时等待重试。这是解释器既有行为，已写入说明。
- 携带上述结构的流程，在每组修改结束时都要通过 machine 第 1–8 阶段（结构、路由、循环、并行、条件、取值）的检查。第 9 阶段起需要发布证明，草稿阶段不跑。例如验证回路内的审批会因侧向退出被拒。
- `step_add` 跳过失败边，接在成功出口上。`step_remove` 移除审批后紧接的步骤时保留条件路由，交付来源回溯到审批前最近的成员步骤。设置了失败分支的步骤和失败分支的首步都不能直接移除，必须用 `on_failure_remove`。

## 发现

machine 的取值检查（第 8 阶段）原先把失败边当作普通边计算支配关系，失败分支读取失败步骤的结果能通过校验，运行时却取不到值。内核已在 #104 修复，编辑侧直接依赖第 8 阶段拒绝这种写法，不再另做检查。

## 界面与 MCP

- `weave_development_read` 的步骤视图新增“人工审批”（含审批说明、审批人）、“条件分支”、“循环”，并在后续步骤上标注“失败时”“条件满足时”“其他情况”“超时”。
- MCP 入口说明新增一句：要求出错时按规定处理时，用 `guarantee` 类别设置失败分支。
- 管理端画布为人工审批和条件节点显示专用图标与类型，失败边以虚线标出，并在边上标注“批准”“驳回”“失败时”。审批步骤的检查器只读显示审批说明与审批人。

## 验证

- `internal/app/api/team_development_guarantees_test.go`：审批与失败分支的构造、移除后恢复原样、与 `step_add`/`step_remove` 的交互、各类拒绝（并行分支、重名、结果分类、业务回执流程、定时触发、验证回路内）、MCP 草稿视图。
- `internal/kernel/teamrun/workflow_approval_test.go`：从人工审批恢复后，`approve` 交付工作结果，`reject` 交付审批意见。
- 修改类别目录测试计数由 23 更新为 25；`TestApprovalIsNotOfferedInTheGuide` 确认指南与入口说明不提供审批，但修改仍被接受。
- 管理端改动未在本机运行类型检查与测试：npm 配置禁止远程获取依赖（`EALLOWREMOTE`）。
