## 1. 交付卫生（挡在一切之前）

| 项 | 内容 | 阻塞 |
|---|---|---|
| H1 | weave-next 建 git remote 并推送（命名待用户裁决） | 无 remote = 无 CI = 预算/depguard 门禁不在 CI 强制 |
| H2 | CI 里设 `TEST_DATABASE_URL` 跑真库全量（现已零豁免全绿，值得锁进 CI） | 依赖 H1 |
| H3 | 有 Docker + 真实凭据的环境补验 3 项 PARTIAL parity（create_team 全链、MCP 完整转发、memory auto-remember） | 通过后老仓方可归档 |
| H4 | 老仓归档（README 置顶 + 只读保护） | 依赖 H3 |

## 2. 架构债（按优先级）

| 优先级 | 项 | 出处 |
|---|---|---|
| 高 | **compiler candidate 路径预算闸**：runCompilerV1 无前/后 budget gates、scenario 循环间无检查、tool_calls 记零——"先超支后照常发布"。这是评测自动额度（M2b v1 砍掉的功能）的先决条件 | M2b 互审 |
| 高 | **部分物化恢复语义**：blocked run 的幂等恢复（复用已物化资产 ID、operation ledger），团队 building→active 时机后移；不建议物理删除资产 | M1 验收报告建议 |
| 中 | **kernel 瘦身遗留**：64 个 deadcode 存疑候选的逐项归档复核（S0 只删了铁证部分，净 -4.67%） | S0 报告 |
| 中 | **depguard baseline 1 消解**（teamrun→kernel workflow/loomruntime，11 处）：executor 拆分后评估能否继续收窄 | S0 |
| 低 | **evaluation 自动额度**：依赖预算闸；含日/月/并发聚合口径扩展 | M2b |
