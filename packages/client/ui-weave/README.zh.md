# `@deepseek-ai/dsh-client-ui-weave`

[English](README.md) | 中文

## 概述

`dsh-client-ui-weave` 把持久化的 Weave MCP 调用结果转成可见的工作任务，并把运行节点管理放进同一个 Workbench 界面。用户无需阅读内部编号或工具术语，就能跟踪已选团队、进度、成员活动、运行位置、人工决策和严格归属当前运行的交付物。

## 使用此包

在 `ui-chat` 和 `ui-tool` 之后挂载本包。设置页负责运行节点管理。会话标题旁的任务入口默认在对话旁打开现有工作现场，全幅查看需要用户主动选择。现场分为“进展”和“成果”页签。执行中优先展示恢复、纠偏和成员。失败任务默认打开进展，在现场和主对话的紧凑回执中说明失败阶段，并可展开原始原因。完成任务默认打开成果，已停止任务仅在有保留成果时默认打开成果。已派发任务缺少团队名称时，不再显示正在匹配团队。页签选择和最多三名关注成员属于浏览器阅读偏好。成员执行记录展示实际运行位置、阶段、可读输入、工具活动及可直接展开的已有产物。“提出调整”在原输入框插入可读引用，保留已有草稿且不自动发送。引用携带确切的运行、成员、阶段和产物身份，供后续讨论使用；它不建立独立成员对话或独立暂停。

主对话通过 `conversation.input.dock` 保留一张紧凑任务回执，仅展示当前状态、可用操作、最终成果直达入口和阶段产物数量。完整成员记录与成果预览留在工作现场。人审答复、纠偏范围和操作历史由用户主动展开；重试、停止和纠偏确认仍可在主对话完成。已处理操作保留真实的接收或拒绝回执，接收请求不表示执行完成。人审表单沿用 Weave `resume_schema` 声明的字段名和类型；复杂结构引导回到讨论，不擅自构造自由文本答复字段。普通提问不会自动提交纠偏。

等待任务区分定时暂停、团队阶段、人审答复、纠偏确认和执行环境中断。当 Weave 明确当前中断阶段尚在等待原执行停止确认时，主对话、工作现场和成员记录指出对应阶段，并说明先恢复运行节点连接。仅在 Weave 返回该阶段可重试后提供入口，不将确认尚未到达说成永久无法恢复。重试必须对应当前可恢复的确切等待，运行中、停止中和终态不会露出旧失败的重试入口。只有已确认取消才显示“已停止”；仅在 Weave 根据对应取消状态迁移返回 `stop_unconfirmed` 时，显示停止状态未能确认。运行完成却缺少 `artifact_kind=final` 最终产物时，页面明确保留交付缺口，优先核对已有工作，不提供成功评价。无文件名的最终交付结论仍是最终成果，阶段或未知类型产物不具备这一资格。

成员公开更新依据实际运行节点能力展示。新近观测到执行中时，任务与成员状态点轻微闪动，也包括分工等待中仍有成员运行的情况。主对话和工作现场指出正在执行的成员，对应阶段运行时最新公开记录短暂高亮，不生成占位文字流。停止确认等待、过期观测、停止中和终态保持静止，并尊重减少动态效果偏好。支持的新版本 Codex 节点可在执行中发布公开文字和工具事件，其他或旧节点在阶段完成后更新。公开记录与最终成果分开，不包含私有推理。用户向上阅读历史时，新记录不会抢占滚动位置；可主动回到最新记录。截断状态明确可见。侧栏项目动态只读取工作区明确关联会话的当前持久化任务，同一运行按最新观测去重，排除归档和未关联会话，并明确说明缺失记录。任务和成果入口返回原工作对话；取得最终产物不等于质量已验收。

<a id="understand-the-implementation"></a>
## 理解实现

浏览器复用工具视图、会话标题、详情、输入框附属区、设置和工作区项目动态插槽。Host 负责持久化 `workTask` 投影、后台轮询，以及鉴权后的任务操作与正文路由。浏览器展示和阅读偏好不形成另一套执行状态。项目导航等待目标会话视图实际就位后再打开现场，避免会话切换时的布局清理关闭刚请求的现场。

产物正文仅在展开后渲染。Markdown 使用共享渲染器；SVG 通过鉴权正文路由以图片展示，并带沙箱 CSP；HTML 使用受严格 CSP 约束的静态沙箱文档。完整下载经 `/api/weave.deliverable` 转发到 Weave 现有 `/v1/deliverables/:id/content`，即使投影预览被截断仍可读取后端保留的完整正文。Host 校验会话、运行和产物的关联，不向浏览器暴露业务密钥，也不从生成文字中猜测本地路径或应用访问地址。

CSV 与 TSV 表格最多预览 200 行、40 列；SVG 图片提供明确缩放控件。预览受限时使用真实完整正文下载入口。返回成员或页签时保留成员选择及最多 100 个阅读位置，包括跟看与未读状态；翻阅历史不会把新内容标记已读。项目成果链接回到原对话并展开确切产物。

<a id="model-experience"></a>
## 模型体验

无独立模型调用，因为浏览器包通过现有对话提交用户明确选择的引用和讨论内容。

#### KV Cache 影响

投影刷新不增加模型上下文；用户明确提交的内容会扩展现有对话，并正常影响其上下文和缓存。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- **每个 Session 只展示一个任务**——当前投影跟踪 Session 中最近一次 Weave 派发；多派发任务分组仍暂缓。
- **运行进程仍由所在机器控制**——运行节点中心管理注册与调度事实，不会声称可以从浏览器启停本地 Codex、Claude Code、OpenCode 或内置执行进程。
- **紧凑 JSON 是输入合同**——非数组结果，或缺少稳定 ID 与名称的团队条目，会进入格式异常状态。
- **交付物是远端不可变文件**——Workbench 可以预览和下载已记录正文，但不会把它物化到当前工作区。
